Why I still prefer the open web

A short argument for choosing inspectable web technology, open formats, and your own domain over closed publishing platforms.

Aug 8th, 2026 By Ferox Filed under Web

There is still a strong case for building personal sites with plain web technology.

Not because it is nostalgic, and not because newer tooling is inherently bad. The case is simpler than that: websites age better when their moving parts are obvious.

The useful constraints

Static output imposes a healthy discipline:

  • URLs become intentional.
  • Content stays portable.
  • Hosting becomes cheap and replaceable.
  • Failure modes become easier to understand.

When the site is just HTML, CSS, media files, and a feed, there is less that can decay invisibly.

What “modern” should mean

Modern web work does not need to mean maximal complexity.

For a personal site, modern should mean:

  • excellent typography
  • responsive layouts
  • accessible markup
  • fast navigation
  • durable deployment

That baseline is enough for a large class of sites, especially blogs.
